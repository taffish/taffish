# TAFFISH v0.12.0

## What changed

- The macOS 15+ Apple Silicon builds of `taf`, `taffish`, and `taffish-mcp` now use SBCL 2.4.9 built without core compression, removing the Homebrew zstd dependency. All three link only to macOS system libraries and run without a separate Lisp installation.
- The three commands are distributed together in a platform archive: `.tar.xz` for Apple Silicon macOS and `.tar.gz` for the Linux LispWorks build. macOS uses the system tar to unpack it; Linux needs tar and gzip.
- The Gitee installer automatically downloads and reassembles smaller archive parts on macOS before verifying the complete archive. GitHub and Linux downloads continue to use complete archives.
- `--local` selects the matching platform package and skips the online index update. With `--verify gpg`, the installer authenticates the archive before extraction and the three executables before installation. [Local installation and verification](../../install/README.md)
- TAFFISH bundles Han Lisp 0.3.0. Hub repair uses its atomic file replacement when updating an existing transaction journal, including on ECL and CCL.
- Source builds support all three commands with CCL or ECL. Rebuilding an extensionless launcher on ECL now preserves its exact name. [Source build guide](../dev/en/build-from-source.md)
- ECL now shows live progress in an interactive terminal and keeps progress control characters out of redirected output.
- Concurrent `taf run` invocations now use separate temporary directories for their generated scripts.

## Upgrade notes

- Linux installations request acceptance of the bundled LispWorks runtime terms. After reading them, unattended installers can pass `--accept-runtime-license`. [Runtime licenses](../../install/README.md#runtime-licenses)
- When upgrading from 0.11.0 on Apple Silicon, keep Homebrew’s `zstd` installed until the upgrade finishes. The installer runs the old SBCL executables to identify them before replacement.
- If your deployment scripts download individual programs from a release tag, switch to the platform archive under `target/packages-0.12.0/` and keep its signed checksum manifest and release public key alongside it. For Gitee macOS downloads, follow the archive-part layout described in [package names and verification files](../../install/README.md#versioned-downloads).
- macOS CCL development builds have an unresolved intermittent native crash. Use the official SBCL package for deployment; see the [development build notes](../dev/en/build-from-source.md#developer-builds-with-ecl-or-clozure-cl).
