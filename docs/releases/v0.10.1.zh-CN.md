# TAFFISH v0.10.1 Release Notes

TAFFISH v0.10.1 是一个 patch release，重点是修复 TAFFISH compiler 的正确性问题，
并扩展外部 conformance 覆盖。

## 重点更新

- 修复 `@:` block-slot 参数渲染问题，确保追加参数 token 被生成为 shell token，
  而不是内部 Lisp 结构。
- 扩展外部 TAFFISH conformance 测试，覆盖文档化语法和真实 source/stdin 编译行为。
- 保持 `taf`、`taffish` 和 `taffish-mcp` 公共接口与 v0.10.0 兼容。

## 兼容性

v0.10.1 设计上与 v0.10.0 以及之前的 0.x release 向后兼容。它不引入新的 TAF
语言特性，而是修复一条错误渲染路径并加强回归测试覆盖。

## 安装

默认 GitHub 安装：

```sh
curl -fsSL https://raw.githubusercontent.com/taffish/taffish/main/install/install-taffish.sh | sh -s -- --user
```

固定 v0.10.1 安装：

```sh
curl -fsSL https://raw.githubusercontent.com/taffish/taffish/main/install/install-taffish.sh | sh -s -- --version 0.10.1 --user
```

中国/Gitee 安装：

```sh
curl -fsSL https://gitee.com/taffish-org/taffish/raw/main/install/install-taffish.gitee.sh | sh -s -- --version 0.10.1 --user
```

## Release 校验

二进制载荷位于 release tag 的 `target/` 下。每个 release payload 应包含：

```text
target/SHA256SUMS
target/SHA256SUMS.asc
target/TAFFISH-RELEASE-KEY.asc
```

v0.10.1 的 checksum manifest 是：

```text

```

校验 SHA256：

```sh
cd target
shasum -a 256 -c SHA256SUMS
```

校验 checksum 签名：

```sh
gpg --import TAFFISH-RELEASE-KEY.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
```

信任 `TAFFISH-RELEASE-KEY.asc` 之前，请把导入后的 release key fingerprint 和下面这个公开 fingerprint 对比：

```text
F863 33E6 0BD6 74F1 59A5  651A B919 3F30 C424 7BB2
```

v0.10.1 的准确 checksum manifest 以 v0.10.1 tag 内的 `target/SHA256SUMS` 文件为准。
重新构建带版本号的二进制后，不要复用旧 release 的 manifest。
