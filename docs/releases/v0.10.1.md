# TAFFISH v0.10.1 Release Notes

TAFFISH v0.10.1 is a patch release focused on TAFFISH compiler correctness and
external conformance coverage.

## Highlights

- Fixes block-slot argument rendering for `@:` parameters so appended argument
  tokens are emitted as shell tokens instead of internal Lisp structures.
- Expands external TAFFISH conformance tests for documented syntax and real
  source/stdin compilation behavior.
- Keeps the `taf`, `taffish`, and `taffish-mcp` public interfaces compatible
  with v0.10.0.

## Compatibility

v0.10.1 is intended to be backward compatible with v0.10.0 and earlier 0.x
releases. It does not introduce a new TAF language feature; it fixes an
incorrect rendering path and strengthens regression coverage.

## Release Verification

The binary payload is stored under `target/` in the release tag. Each release
payload should include:

```text
target/SHA256SUMS
target/SHA256SUMS.asc
target/TAFFISH-RELEASE-KEY.asc
```

Verify checksums:

```sh
cd target
shasum -a 256 -c SHA256SUMS
```

Verify the checksum signature:

```sh
gpg --import TAFFISH-RELEASE-KEY.asc
gpg --verify SHA256SUMS.asc SHA256SUMS
```

Before trusting `TAFFISH-RELEASE-KEY.asc`, compare the imported release key
fingerprint with this public fingerprint:

```text
F863 33E6 0BD6 74F1 59A5  651A B919 3F30 C424 7BB2
```

The exact checksum manifest for v0.10.1 is the `target/SHA256SUMS` file in the
v0.10.1 tag. Do not reuse a previous release's manifest after rebuilding
versioned binaries.

## Supply-Chain Notes

This release continues the current manual binary release model: signed checksum
manifests are provided, but GitHub Actions provenance, artifact attestation, and
reproducible builds are not yet claimed.
